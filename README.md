# visual-craft

Skill de Claude Code que crea cualquier pieza visual (intro/animación de scroll, UI, rediseño, pixel art, tipografía…) a partir de una idea de una frase. Incluye copias de otras skills de diseño (ver `NOTICE.md`; repo privado por sus licencias).

## Instalar

```bash
git clone https://github.com/thejowe/visual-craft ~/.claude/skills/visual-craft
```

Se invoca con `/visual-craft <idea>` o pidiendo algo visual.
